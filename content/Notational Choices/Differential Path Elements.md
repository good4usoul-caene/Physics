### Lorentz Transformations

| Description             | Standard Representations                                                                                                                      | Global Choice                                                                                            |
| ----------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| velocity                | $$v, v_x, v_y,v_r,v_\phi$$                                                                                                                    | $$v, \beta c, \beta_r c, \beta_\phi c$                                                                   |
|                         | Forms of velocity might divide it into components...  $v_x$ and $v_y$ in a Cartesian coordinate system, or $v_x, v_\phi$ in polar coordinates | I prefer to represent velocity as a combination of the unitless $\beta$ quantity multiplied by $c$. <br> |
| Tangential velocity     | $$v_\phi= r\dot\theta, v_\phi=r\omega$$                                                                                                       | $$\beta_\phi=\frac{r\omega}{c}=\frac{r\dot\phi}{c}\\ v_\phi=c\beta_\phi$$                                |
| Radial velocity         | $$v_r=\dot r$$                                                                                                                                | $$\beta_r=\frac{\dot r}{c}\\v_r=\beta_r c$$                                                              |
| Parametric path         | $$\vec r(t)=(x(t),y(t))$$                                                                                                                     | $$\vec h(t)=(x(t),y(t))$$                                                                                |
| Velocity<br>(Cartesian) | $$\vec v = \frac{d\vec r}{dt}=(\dot x, \dot y)$$                                                                                              | $$\vec \beta c=\frac{d\vec h}{dt}=(\dot x, \dot y)$$                                                     |
