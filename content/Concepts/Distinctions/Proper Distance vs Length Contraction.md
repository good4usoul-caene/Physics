The distinction is as follows

- **Proper Distance** - Instantaneous distance between two specific events from *the unique* point-of-view where those events are simultaneous.
- **Length Contraction** - Instantaneous distance between parallel world-lines from *any* point-of-view

For most people, imagining the velocity for which two distant events become simultaneous is not an intuitive task. For reference, though, if $\frac{\Delta x}{c\Delta t}=\frac{1}{\beta}$, where $\beta<1$ then one must choose a velocity of $v=\beta c$.  We can call it the [[wave-front intuition]].


Two big differences:

| Quantity           | Structure                      | POV                                                                                          |
| ------------------ | ------------------------------ | -------------------------------------------------------------------------------------------- |
| Proper Distance    | Two Events                     | The **one point-of-view** where the two events appear simultaneous                           |
| Length Contraction | Two ends of a traveling object | Any point-of-view is used.  Select two simultaneous events; one from each end of the object. |
Additional Note
- Shortest Proper distance is obtained when events appear simultaneous
- Longest uncontracted length is obtained when object is stationary.

# Proper Time vs Time Dilation

The distinction here is not usually as problematic because it is very intuitive to conceptually pick out the unique inertial frame where two consecutive events take place at the same location.  One need only imagine themselves standing with a clock.  

| Quantity      | Structure  | POV                                                                                                                |
| ------------- | ---------- | ------------------------------------------------------------------------------------------------------------------ |
| Proper Time   | Two Events | The one point-of-view where the two events happen at the same place                                                |
| Time Dilation | A clock    | Any point-of-view is used.  Select two events on the same clock and note that it ticks slower than inertial clocks |
What is not usually discussed is two moving, synchronized clock.
