# Allow Words to have Multiple Meanings

1. Words have multiple meanings.  When using a dictionary, you can generally find several  established meanings of a word.  
2. When a word is carefully chosen in communication, be sure to know which meaning is intended.
3. Do not oppose a concept from discussion simply because an appropriate word is being used.  Rather, suggest a more appropriate word, and move forward.
4. Be careful when a single word has multiple meanings that sound very similar.
   
# Application to Mathematics
1. In mathematics, variables are frequently used in order to describe quantities.
2. When possible, avoid the use of multiple ideas with a single variable symbol.  These are homonyms, in the sense that the term looks and sounds the same, but it means something different.
3. If someone else uses a single variable to represent multiple quantities, take the time to introduce new variable symbols with, for instance, subscripts.
